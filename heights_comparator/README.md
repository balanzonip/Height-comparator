#Heighth_comparator

a python project that compares your height, that must be typed by the user in the file 'your_height.csv', with other elements stored in the file 'other_heights.csv'.

##requirements
-python
-matplotlib

Install the dependency:
'''bash
pip install -r requirements.txt


##Run
Place 'your_height.csv' and 'other_heights.csv' in the project folder,then run:
'''bash
python main.py
remember to give your height, otherwise an example value will be used.

##What i learned
-Reading structured CSV data in Python
-Working with lists, loops, conditions and functions
-Calculating summary statistics
-Plotting data with matplotlib
